What this is counting, and what it cannot tell you

created means the token program created the mint in a transaction this wallet paid for. A transaction that creates one token often buys others: those mints appear beside it in the same transaction but are not creations, and are not counted here.

swept means this wallet submitted a fee collection for a mint it also created in this scan (SweepCreatorFee, CollectCreatorFee, CollectCreatorFeeV2). Collection is permissionless — any signer can trigger it, and bots do — so a sweep on its own says nothing about who owns the mint. It appears here only when the same wallet also created the mint.

Two wallets are linked when one funded the other. That is a link, not proof: exchanges and faucets fund thousands of unrelated wallets. Every edge keeps its signature so you can check any single line in an explorer.

The page only sees the last N transactions, so a busy wallet's older launches are invisible here. It does not tell you who sold, who profited, or whether a token was a scam. It reports what the chain says.

The default RPC is a free public endpoint. Large scans will be slow or rate-limited; paste your own RPC URL under “RPC” if you have one.

Questions this page answers

Who is the dev wallet of a pump.fun token?

The creator is the wallet that paid for the transaction containing the Create instruction. On a fresh token that transaction is the mint's first transaction, so it is the oldest signature on the mint — expensive to reach once the token has been trading for hours. A fee collection does not answer the question: it is permissionless, and the signer is often a bot rather than the creator. This page therefore starts from a wallet, not a token.

Is it the creator, or just the first buyer?

A buy is not a creation. A transaction can create one token and buy three others, and all four appear in its account list. This page counts only mints the token program actually initialised, so a wallet that merely bought the token is not shown as its creator.

Can two wallets be the same creator?

They can be linked: the graph draws an orange edge when one funded the other. That is a lead, not proof — exchanges and faucets fund thousands of unrelated wallets. Every edge keeps its signature so you can check the transfer yourself.

Does this tell me whether the dev sold?

No. Selling is a swap out of a token account, and this page maps creation and control, not disposal. Anyone claiming a graph like this proves a dump is adding something the data does not contain.

Is it free, and does it need an API key?

Free and MIT licensed. The page talks to a public Solana RPC from your browser, so there is no signup and nothing to install. Rate limits are the only cost; you can paste your own RPC endpoint if you have one.
