solana-launch-forensics

Read-only forensics for pump.fun style launches. Standard library only, MIT, every output line traceable to a transaction signature.

pip install solana-launch-forensics

Browser demo → Paste a wallet, see which tokens it created and whose creator fees it collected. No install, no API key. Sample report → What the paid write-up looks like: 96 launches, funding chain, payout reconstruction. Source on GitHub → CLI, dataset schema, tests. MIT licensed. PyPI → Installs with pip or uv, Python 3.10+.
